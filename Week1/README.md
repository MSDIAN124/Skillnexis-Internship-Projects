# Sales Performance Dashboard – Excel

## Project Overview

This project was completed as part of my **Week 1 Data Analytics Internship assignment at SkillNexis**.

The objective was to create an interactive **Excel Pivot Table Dashboard** to analyze sales performance and present key business insights in a clear, decision-friendly format.

The dashboard focuses on:

- Total revenue
- Sales by category
- Yearly sales trends
- Department-wise sales performance

## Business Objective

The purpose of this dashboard is to help stakeholders monitor overall sales performance, identify high-performing categories and departments, and understand sales trends across different years.

It converts raw sales data into a summarized visual report using Excel Pivot Tables, Pivot Charts, slicers, and KPI cards.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel formulas
- Data cleaning and formatting
- Dashboard design and visualization

## Dashboard Features

The Excel dashboard includes the following analysis:

| Analysis Area | Description |
|---|---|
| Total Revenue | Displays the overall revenue generated from all recorded sales transactions |
| Sales by Category | Compares sales performance across different product categories |
| Yearly Sales Trend | Shows how sales revenue has changed over the years |
| Department-wise Sales | Highlights which departments contribute the most to total sales |
| Interactive Filters | Allows users to filter and explore the dashboard data dynamically, if slicers are included |

## Key KPIs

The dashboard is designed to track the following key performance indicators:

- Total Revenue
- Total Sales Amount
- Category-wise Revenue
- Department-wise Revenue
- Year-wise Sales Growth or Trend

## Dataset Description

The dataset contains sales-related information used to create the dashboard. Typical fields included in the analysis are:

| Column Name | Description |
|---|---|
| Row ID | ID for each Row |
| Order ID / Invoice ID | Unique identifier for each sales transaction |
| Order Date | Date on which the order was placed |
| Ship Date | Date on which the order was Shipped | 
| Customer ID| ID of Customers who placed order|
| Customer Name | Name of the customer |
| Segment | include Corporate and Home office |
| Postal ID | describes address of the order delivery|
| City | Name of The city of customer |
| State | State of the customer |
| Country | country from where order placed |
| Region | describes region |
| Market | describes global markets |
| Product ID | ID of a  each product |
| Category | Product category associated with the sale |
| Sub-category| Subcategory of product |
| Product Name | Name of the product sold |
| Sales / Revenue | Revenue generated from the transaction |
| Quantity | Number of units sold, if available |
| Discount | discount given on each order |
| Profit | profit earned on each product |
|Shipping Cost | cost of shipping the order |
|Order Priority | describe about the priority behind each order|

## Dashboard Insights

The dashboard can be used to answer important business questions such as:

- What is the total revenue generated by the business?
- Which product category generates the highest sales?
- Which department contributes the most to revenue?
- How has sales performance changed year by year?
- Are there any years with a noticeable increase or decrease in sales?
- Which categories or departments may need more attention from management?
