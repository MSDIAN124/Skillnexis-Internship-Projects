# Sales Performance Dashboard – Power BI

## Project Overview

This project was completed as part of my **Week 4 Data Analytics Internship assignment at SkillNexis**.

The objective of this project was to create an interactive **Power BI Sales Performance Dashboard** that analyzes sales, profit, cost, product performance, country-wise performance, and monthly sales trends.

The dashboard converts raw financial and sales data into interactive visual insights that can help business stakeholders monitor sales performance, identify profitable products, compare costs, and explore performance across countries and months.

## Business Objective

The main goal of this dashboard is to provide a clear overview of business sales and profitability.

The dashboard helps answer questions such as:

1. What are the total sales, total profit, and total cost of goods sold?
2. Which products generate the highest profit?
3. Which countries generate the highest sales?
4. How do sales change from month to month?
5. Which products generate the highest sales?
6. How does COGS compare with manufacturing price for each product?
7. How do sales and profitability change when users filter by product, country, or month?

## Dataset Description

The dataset contains sales, product, pricing, cost, discount, date, and geographic information.

| Column Name | Description |
|---|---|
| `Segment` | Customer or business segment, such as Government, Midmarket, Enterprise, Small Business, and Channel Partners |
| `Country` | Country where the sale was recorded |
| `Product` | Product name |
| `Discount Band` | Discount category or discount range applied to the sale |
| `Units Sold` | Number of units sold |
| `Manufacturing Price` | Cost of manufacturing one unit of a product |
| `Sale Price` | Selling price per unit |
| `Gross Sales` | Total sales value before discounts |
| `Discounts` | Discount amount provided to customers |
| `Sales` | Net sales value after discount adjustments |
| `COGS` | Cost of Goods Sold associated with products sold |
| `Profit` | Profit generated from sales after deducting relevant costs |
| `Date` | Date of the sales transaction |
| `Month Number` | Numeric representation of the month used for correct month sorting |
| `Month Name` | Name of the month |
| `Year` | Year of the transaction |

> Note: The dashboard uses `Month Number` to sort `Month Name` correctly from January to December rather than alphabetically.

## Dashboard KPIs

The dashboard contains three KPI cards created using DAX measures.

| KPI | Description |
|---|---|
| Total Sales | Total net sales generated from all transactions |
| Total Profit | Total profit earned across all transactions |
| Total COGS | Total Cost of Goods Sold incurred across all transactions |

## DAX Measures

The following measures were created to calculate the main dashboard KPIs.

```DAX
Total Sales = SUM(Sheet1[Sales])
```

```DAX
Total Profit = SUM(Sheet1[Profit])
```

```DAX
Total COGS = SUM(Sheet1[COGS])
```


## Dashboard Visuals

The dashboard includes the following visuals:

| Visual | Analysis Provided |
|---|---|
| Total Sales Card | Displays total net sales generated |
| Total Profit Card | Displays total profit generated |
| Total COGS Card | Displays the overall Cost of Goods Sold |
| Product-Wise Profit Chart | Compares profit generated by each product |
| Country-Wise Sales Chart | Shows sales performance across countries |
| Monthly Sales Trend Chart | Displays sales trends across months |
| Sales by Product Chart | Compares total sales across products |
| COGS vs Manufacturing Price by Product | Compares product manufacturing cost with Cost of Goods Sold |

## Interactive Slicers

The dashboard contains three slicers that allow users to filter all visuals dynamically.

| Slicer | Purpose |
|---|---|
| Product | Filters KPIs and charts for a selected product |
| Country | Filters performance metrics based on selected country or countries |
| Month Name | Filters dashboard results for a selected month |

These slicers make the dashboard interactive and allow users to perform product-level, country-level, and monthly sales analysis.
